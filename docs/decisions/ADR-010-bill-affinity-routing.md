## 1. 背景与目标

打印店有多台打印机（A4 彩色双面、A4 黑白、A3 机……）。顾客（= 一个账单）一次交多个文件，
若每个文件各打一台，取件要在多台机器之间拼凑。目标：

1. **同一账单的文件尽量落在同一台打印机**（取件集中）；
2. **不同账单尽量落在不同打印机**（负载均衡，也减少两位顾客在同一台机器上排队的混拿风险）；
3. 能力差异（只能黑白 / 只能 A4 / 不支持双面）导致必须分散时，分散到真正能打的那台；
4. 能力声明来自**人工配置的路由规则**，检测只做辅助校验；**没有默认打印机兜底**——没规则能打
   就是未路由，人工补规则后再转发。

## 2. 路由规则 = 打印机能力声明

### 2.1 规则形态

每条规则 = **一台打印机 + 纸张集合 + 颜色集合 + 单双面集合 + 启用开关**：

- 集合内部 OR、集合之间 AND（沿用现有匹配逻辑）；
- 去掉 `Priority`、`MinPages/MaxPages`、`SourceAppPattern`、`DocumentNamePattern`
  （UI 移除，库列保留但废弃）；
- 不同打印机之间允许重叠（这正是亲和/均衡挑选的空间）；
- **同一打印机不允许重复声明**：规则展开成 `(纸张, 颜色, 单双面)` 单元格后，同一打印机的任意两条规则
  不得重叠；保存时校验并报出冲突组合（如「P2 已声明 A4 + 黑白 + 单面」）；
- 规则名称自动生成（`打印机名 · 纸张 · 颜色 · 单双面`），只用于展示与日志。

### 2.2 候选集

```
E = { 规则.目标打印机 | 规则启用 ∧ 规则匹配任务 ∧ 打印机启用 ∧ 文档格式兼容 }（去重）
```

`E` 为空 → `Unrouted`（原因：「没有规则声明能打该任务（纸张/颜色/单双面/格式）」）。

### 2.3 选择策略（两级：同单优先 → 跨账单均衡）

**第一级：同单优先**（同一人取件集中）

- 本账单已有任务用过的打印机 ∩ E，按（本单任务数 desc、最近使用 desc）取第一台 → 同单沿用；
- 命中即结束。

**第二级：跨账单均衡**（不同人尽量不同机）

- 在 E 内计算每台打印机的「**其它未结账单占用数**」= 该机上 `BillId ≠ 当前账单` 且账单未结账
  （Active / Parked）的去重账单数；
- 取占用数最少的一台（0 优先 → 尽量让新账单用空闲机器）；
- 并列时：**最久未使用优先**（按该机最近成功转发时间升序，空值视为最久），再按打印机名称序，保证确定性。

> 同单已用打印机哪怕正被本单占用，也优先于均衡；均衡只在"本单还没有用过的机器"里挑。
> 跨账单分散是"尽量"，当 E 里所有机器都被其它账单占用时按占用数最少分配。

### 2.4 已去掉的旧行为

- **默认打印机**：路由不再有默认机兜底；打印机页去掉「设为默认」按钮与「默认」列，
  打印机编辑窗口去掉「设为默认打印机」勾选；`Printer.IsDefault` / 库列保留但废弃。
- 演示数据里的"默认机"初始化同步删除。

### 2.5 升级迁移引导（重要）

去掉默认机后，**没有任何路由规则的库**会把所有新任务标为未路由。首次升级时：

- 若打印机能力**已检测**（做过测试连接）：自动为每台启用打印机生成一条覆盖其探测能力的能力规则
  （纸张/颜色/单双面取检测结果），避免升级后"全部打印不了"；
- 若能力**未检测**：不自动生成，收银台/打印机页提示「请先配置路由规则」；
- 自动生成的规则在路由规则页可编辑/删除，并在日志里记录「升级自动生成」。

## 3. 探测能力的用途（仅辅助配置）

| 场景 | 已检测 | 未检测 |
|---|---|---|
| 路由规则编辑 | 纸张/颜色/单双面选项限制为该机支持范围，非法组合**禁止保存**并提示原因 | 不限制，用户配什么就是什么（提示"未检测，规则以你的配置为准"） |
| 规则列表 | 条件与检测能力不一致时标黄提示（不阻断） | 不提示 |

不新增"手工填能力"界面——能力就是规则本身。

## 4. 价格表

- **唯一键 `(纸张, 颜色)`**：同一组合只允许一行，库层加唯一索引；
- **去掉优先级**：查价即精确命中；
- **去掉启用**：所有行始终生效；
- **去掉"其他纸张"通配行**：默认表只保留 A3/A4/A5 × 黑白/彩色 6 行；
- 每行仍包含**单面价 / 双面价**（按张计价规则不变）；
- **缺价处理**：计价时找不到精确匹配 → 任务 `NeedsReview`（原因「未配置该纸张/颜色的价格」）；
  收银台结账被阻止，弹窗列出问题任务并提供「去配置价格表」入口；补价后可继续结账。

数据迁移：

1. 删除 `PaperSize` 为空 / `*` 的通配行；
2. 同一 `(纸张, 颜色)` 多行时保留 `UpdatedAtUtc` 最新的一行；
3. `Enabled` 置 1、`Priority` 置 0（列废弃保留）；
4. 建唯一索引 `(PaperSize, ColorMode)`（空颜色按 Unknown 处理）。

## 5. 手动「选择目标」

- 人工转发/重试只列出 **E 内**的打印机；其余置灰并给原因「路由规则未声明该打印机支持此任务」；
- E 为空时不允许人工转发，提示先补路由规则（提供「去配置路由规则」入口）；
- 不支持强制使用不支持的机器。

## 6. 配置与数据

| 项 | 变化 |
|---|---|
| `RoutingRule` | 去 Priority / 页数范围 / 来源正则 / 文档名正则；保留 Enabled；同打印机重叠校验 |
| `PriceRule` | 去 Priority / Enabled / 通配行；唯一键 `(纸张, 颜色)`；名称自动生成 |
| `Printer.IsDefault` | 废弃：UI 去掉，库列保留不读不写 |
| 设置 `billAffinity` | 布尔默认开；设置→转发卡片：勾选「同一账单优先使用同一台打印机」 |
| 库迁移 | 价格表清理 + 唯一索引；其它列废弃保留（不删列） |

## 7. 示例

规则：

- P1（A4 彩色双面）：A4；黑白+彩色；单面+双面
- P2（A4 黑白）：A4；黑白
- P3（A3 彩色）：A3/A4/A5；黑白+彩色；单面+双面

**账单 A**（先到）：A4 彩色双面 → E={P1,P3}，本单无历史，其它账单占用全 0 → 最久未使用/名称序 → P1；
A4 黑白单面 → E={P1,P2,P3}，同单已用 P1 → **P1**；
A5 黑白单面 → E={P3}（P1 只 A4）→ P3（合理分散，新增取件点）；
A3 彩色单面 → E={P3}，同单已用 P3 → P3。

**账单 B**（同时段另一顾客，同为 A4 彩色双面）：E={P1,P3}；
P1 被其它未结账单 A 占用（1），P3 被 A 占用（1）→ 并列 → 最久未使用：P3 上 A 的 A3 任务更晚？
按转发时间升序取更久未用者，实际会尽量把 B 放到"最近没被用"的那台 → 实现"不同账单尽量不同机"。

## 8. 边界与异常

1. 规则目标打印机被禁用/删除 → 不参与候选；E 为空 → Unrouted。
2. 规则保存冲突 → 报错并列出冲突规则与具体组合。
3. 价格缺失 → NeedsReview + 阻止结账 + 提示补价格表。
4. 转发失败 → 原目标重试 / 人工在 E 内改选；本期不做自动故障转移。
5. 账单结账后重打 → 仍按该账单已用打印机亲和（历史账单任务也参与亲和统计）。
6. 只有一台机器支持某能力时，跨账单均衡失效是预期行为（"打印不了就是打印不了"）。

## 9. 测试计划

- **Core**：
  - 候选集：无/单/多规则、并集去重、禁用规则、禁用打印机、格式不兼容；
  - 亲和：本单已用命中与排序、同单优先压过均衡；
  - 均衡：其它未结账单占用数计算、0 优先、并列时最久未使用/名称序；
  - 规则重叠校验；价格精确匹配与缺价。
- **Storage**：价格表迁移（删通配、去重、唯一索引）；未结账单按打印机统计查询；废弃列读写兼容。
- **Integration**：三台 FakePrinter：同单同机、跨账单分散、E 空未路由、重启后仍亲和、关闭亲和开关后的行为。
- **UI 手测**：设置勾选；打印机页去默认；规则页（去优先级/页数/正则、重复校验、能力限制）；
  价格表（6 行、唯一约束、缺价阻止结账提示）；选择目标只列 E。

## 10. 分阶段落地

**迭代 1（路由核心 + 均衡）**

1. `RoutingEngine` → 候选集 + `AffinityPolicy`（同单优先 + 跨账单均衡）+ E 空未路由；
2. 去掉默认打印机（路由/UI/演示数据）；
3. 规则模型/编辑器精简（去 Priority/页数/正则，同打印机重叠校验，能力限制选项）；
4. `billAffinity` 设置 + 设置页勾选；
5. 单测 + 集成测试。

**迭代 2（价格表与人工）**

6. 价格表精简：6 行、唯一键、去优先级/启用/通配、迁移与唯一索引；
7. 缺价 → NeedsReview + 结账阻止提示（弹窗 + 去配置入口）；
8. 选择目标只列 E（置灰原因）；
9. 文档（`ui.md`/`CHANGELOG`）、ADR 转正。
